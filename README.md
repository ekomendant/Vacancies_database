 Приложение для работы с вакансиями

## Описание:

В проекте разрабатывается приложение для выгрузки вакансий с сайта hh.ru. Все вакансии сохраняются в базу данных 
PostgreSQL. БД используется для вывода результатов поиска пользователям.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/ekomendant/Vacancies_database.git
```

2. Установите зависимости:
```
pip install -r requirements.txt
```

## Получение доступа к PostgreSQL:

В проекте используется обращение к PostgreSQL.
Для работы функций необходимо в файле `database.ini` прописать ваши данные подключения.
